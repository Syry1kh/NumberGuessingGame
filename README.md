# Number Guessing Game
https://roadmap.sh/projects/number-guessing-game

Консольная игра на Java, в которой нужно угадать загаданное компьютером число от 1 до 100

## Возможности

Три уровня сложности:
  Easy — 10 попыток
  Medium — 5 попыток
  Hard — 3 попытки
Подсказки после каждого хода («больше» / «меньше»).
 Подсчет времени, потраченного на угадывание.
Обработка некорректного ввода (защита от ввода букв).
